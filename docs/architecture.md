## 技术选型记录 (ADR)

| ID | 决策 | 理由 | 替代方案 |
|---|---|---|---|
| ADR-001 | FastAPI 作为 Web 框架 | 异步原生、Pydantic 集成、自动文档 | Django Ninja, Litestar |
| ADR-002 | Neo4j 作为图数据库 | 图原生查询、时序关系建模成熟 | SurrealDB, Apache AGE |
| ADR-003 | pgvector 作为向量存储 | PostgreSQL 生态、运维统一、HNSW 索引 | Qdrant, Weaviate, Milvus |
| ADR-004 | Python 作为引擎语言 | Python 全栈，性能关键路径可用 C 扩展优化 | Go, Rust |
| ADR-005 | Celery + Redis 作为任务队列 | 成熟稳定、Python 生态最佳 | arq, saq, Dramatiq |
| ADR-006 | MinIO 作为文件存储 | S3 兼容、私有化部署、开源 | AWS S3, 本地文件系统 |
| ADR-007 | 可插拔嵌入模型 | 不绑定供应商，灵活切换 | 仅 OpenAI, 仅 BGE |

## 关键设计约束

1. **记忆 ≠ RAG。** 图谱操作和向量检索是独立路径，在混合搜索层合并。
2. **图谱操作必须原子化。** Update 关系 + `is_latest` 标志位在单事务中完成。
3. **管线必须可恢复。** 每个阶段状态持久化，支持断点续传和重试。
4. **画像在摄入时计算。** 写时计算 + 缓存，而非读时计算。
5. **所有外部调用必须有超时和重试。** 嵌入 API、OAuth 回调、Webhook 等。
