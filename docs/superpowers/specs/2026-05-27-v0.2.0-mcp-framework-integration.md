## 1. Goals & Non-Goals

### 1.1 Goals

1. **MCP Server** — 实现 Model Context Protocol 服务，Claude Desktop / Cursor / Cline 等可直接调用 Emerald 的 add/search/profile 能力
2. **Vercel AI SDK 中间件** — `withEmerald()` 包装器，自动注入记忆到 system prompt
3. **LangChain 集成** — `EmeraldMemory` 工具类，可作为 LangChain Tool 使用
4. **TypeScript SDK 雏形** — `@emerald/sdk` npm 包，核心四方法
5. **连接器端到端验证** — GitHub + Google Drive OAuth 完整走通，文件自动同步后可搜索

### 1.2 Non-Goals

- **K8s 部署模板** — 仍使用 Docker Compose
- **记忆图谱可视化前端** — 仍无 Web UI
- **Chrome 插件 / Raycast** — consumer 产品形态，defer
- **高级查询改写（LLM 驱动）** — 仍是规则 stub
- **Cross-encoder 重排序** — 仍是关键词 boost stub
- **音频/视频提取生产化** — 仍是基本实现

## 3. MCP Server

### 3.1 协议概述

Model Context Protocol (MCP) 是 Anthropic 推出的开放协议，允许 AI 助手通过标准化接口调用外部工具。Emerald MCP Server 暴露以下能力：

| 工具名 | 功能 | 对应 API |
|---|---|---|
| `emerald_add` | 添加记忆 | `POST /v1/memories` |
| `emerald_search` | 搜索记忆 | `POST /v1/search` |
| `emerald_profile` | 获取用户画像 | `GET /v1/profiles/{id}` |
| `emerald_upload` | 上传文件 | `POST /v1/upload` |

### 3.2 实现

```python
# emerald/mcp/server.py
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("emerald")

@mcp.tool()
async def emerald_add(content: str, entity_id: str) -> dict:
    """Add a memory to Emerald."""
    ...

@mcp.tool()
async def emerald_search(q: str, entity_id: str, search_mode: str = "hybrid") -> dict:
    """Search memories and documents in Emerald."""
    ...

@mcp.tool()
async def emerald_profile(entity_id: str) -> dict:
    """Get user profile from Emerald."""
    ...
```

### 3.3 部署形态

| 形态 | 适用场景 |
|---|---|
| `stdio` | Claude Desktop 本地插件 |
| `sse` | 远程服务，Cursor / Cline 连接 |

## 4. Vercel AI SDK 中间件

### 4.1 接口设计

```typescript
// packages/sdk-ts/src/vercel.ts
import { EmeraldClient } from "./client";

interface EmeraldMiddlewareOptions {
  apiKey: string;
  baseUrl?: string;
  entityId: string;
  mode?: "profile" | "query" | "full";  // 对标 Supermemory
  addMemory?: "always" | "never";
}

export function withEmerald(options: EmeraldMiddlewareOptions) {
  return {
    wrapGenerate: async ({ doGenerate, params }) => {
      // 1. 提取最后一条用户消息作为查询
      const queryText = extractLastUserMessage(params.messages);
      
      // 2. 调用 Emerald profile + search
      const client = new EmeraldClient(options);
      const memories = await client.profileSearch({
        entityId: options.entityId,
        q: queryText,
        mode: options.mode,
      });
      
      // 3. 注入到 system prompt
      const augmentedMessages = injectMemories(params.messages, memories);
      
      // 4. 调用底层生成
      return doGenerate({ ...params, messages: augmentedMessages });
    },
  };
}
```

### 4.2 Prompt 注入格式

对标 Supermemory 的 `defaultPromptTemplate`：

```
User Supermemories:
## Static Profile
- {static_fact_1}
- {static_fact_2}

## Dynamic Profile
- {dynamic_fact_1}

Search results for user's recent message:
- {search_result_1}
- {search_result_2}
```

## 5. LangChain 集成

### 5.1 Tool 接口

```python
# emerald/sdk/langchain.py
from langchain.tools import BaseTool

class EmeraldSearchTool(BaseTool):
    name = "emerald_search"
    description = "Search user's memories and documents"
    
    def _run(self, query: str) -> str:
        results = self.client.search(q=query, entity_id=self.entity_id)
        return format_results(results)

class EmeraldAddTool(BaseTool):
    name = "emerald_add"
    description = "Add a memory for the user"
    
    def _run(self, content: str) -> str:
        self.client.add(content=content, entity_id=self.entity_id)
        return "Memory added"
```
