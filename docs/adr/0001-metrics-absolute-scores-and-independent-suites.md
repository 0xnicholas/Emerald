# 度量体系：绝对分数 + 独立侧质量套件，不追字面三项基准跑分

v0.4.0 路线图将北极星定为「公开基准分数 ≥ Supermemory 同等水平的 80%」，但基准基建实为自编合成场景 + mock 嵌入，且 LongMemEval/LoCoMo/ConvoMem 是 agent+memory 端到端基准——字面复刻需要研究级 harness，测出的分数无法隔离 memory 层的贡献。2026-08-09 审视决定：放弃字面跑分目标，改为（1）合成对抗场景套件 + 真实嵌入 + 绝对分数公开报告 + CI 防回归；（2）新增三个独立侧质量套件：时序正确性（矛盾消解）、遗忘有效性（噪音去除 vs 信号保留）、图谱关系精度；（3）验证 AGENTS.md 已承诺的性能 SLA（画像 <100ms、搜索 P50/P99）。

北极星表述从「≥ Supermemory 的 80%」改为「独立套件全绿 + SLA 达成 + 报告公开」。已否决选项：投资真实 LongMemEval/LoCoMo/ConvoMem harness（工作量为研究级、分数无法归因到 memory 层）；维持 mock 嵌入现状（旗舰声明继续无证据）。
