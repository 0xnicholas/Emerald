# 记忆整合是无损批量结构收敛；B6 立项先于 D2 数据门

B6（roadmap 主题 B：实时记忆整合 / 连续摄入下的图谱压缩）在 2026-08-14 立项（grilling 会话 + 功能三问 gate）。立项决策五点：

1. **B6 v1 边界 = 无损结构收敛**：对象仅为近重复活跃事实（同实体、is_latest=true、语义等价的多条记忆收敛为一条代表记忆）；被整合者保留内容挂历史。**明确排除 LLM 生成新内容**——有损语义整合（MEMANTO daily-summary / Mem0 式）推迟为潜在 v2，由数据重新辩护。
2. **周期批量，不占摄入热路径**：日级 Celery Beat（遗忘批次之后）运行；roadmap「实时」措辞移除。摄入时 `_check_duplicate` 已挡完全重复；相似冗余日级收敛足够。
3. **检测 = 向量候选 + 规则护栏，无 LLM 判定**：向量相似度仅作候选生成（向量是优化层，AGENTS.md 图谱优先）；决定「并 or 不并」的是规则——实体隔离 / 双方 is_latest / memory_type 相同 / 画像引用与高 importance 豁免（复用 `_is_protected` 单点）/ 矛盾否决 / UPDATES 边否决。
4. **处置 = `mark_consolidated` 原子接缝**：被并者 is_latest=false + replaced_by=代表 ID + metadata 记 reason=consolidated；**不建**代表→被并者的 UPDATES 边（否则多跳检索会把刚收敛的重复浮出来）；MENTIONS/EXTENDS/DERIVES_FROM 边重连到代表。
5. **D2 数据门降级为参数校准**：roadmap 决策 D2 原触发条件「M3 末 Staging >100k 节点查询退化才启动」改为「校准相似度阈值与整合激进度的数据来源」——启动与否由 M4 成功标准（10× 流量 P99 < 500ms）与独立侧指标直接要求，不等故障发生。

**功能三问 gate 命中**：独立侧指标——图谱精度（质量套件误并率 = 0 硬门 + 检索保留率）与性能 SLA（M4 P99 目标）。非参照系驱动（GAP.md 列 B6 为 P2 差距，但立项理由独立于「Supermemory 有」）。

**已考虑并否决**：

- **有损 LLM 语义整合**：破坏可审计性（合并后内容非用户原话）、时序上下文失真、无法被确定性质量套件守护；且 AGENTS.md「记忆 ≠ RAG」——事后 LLM 改写把记忆系统拖向摘要系统。推迟，非否决。
- **摄入时实时整合**：热路径延迟不可预测（摄入延迟是观测指标）；「实时」承诺与实现不符，名称误导。
- **UPDATES 链/历史压缩、团→星拓扑折叠**：前者销毁时序档案（AGENTS.md §6），后者破坏 B4 路径透明契约（公开 API 的 path/depth 字段）。

**后果**：

- B5 删死簇、B6 并活冗余——两个维护策略互补对称，共用调度/可观测性/质量套件架构模式。
- 质量套件守护：整合召回率 ≥ 0.95 / 误并率 = 0 硬门 / 检索保留率 ≥ 0.95 + Neo4j 变体，聚合门第 7 节。
- `CONTEXT.md` 新增「整合（Consolidation）」词条；「压缩/合并/去重/摘要」列为 Avoid。
