# Web UI 是产品层，修正路线图范围声明

路线图 §7 将「消费者产品：Web App、浏览器扩展、Raycast 等 Supermemory 已有的产品形态」整体列为 out-of-scope，但 2026-06 至 07 实际投入 6 周建设了 `apps/web`（28K 行：移动端、chat 真实记忆搜索、图谱视图、时间线、登录、dashboard）——产物与范围声明直接矛盾。2026-08-09 决定：**web UI 是私有化部署的产品形态，纳入产品范围**；范围声明修正为「不追消费者插件生态（浏览器扩展/Raycast）」。前端评价标准从「GAP.md 对 Supermemory 的覆盖率」改为「核心循环完整性」（摄入 → 搜索 → 画像 → 对话；自托管单机可跑；移动端可用）。`GAP.md` 降级为能力差距清单，不再是进度指标。已否决：冻结/移除前端（损失产品形态与最佳 demo）；前端升级为第一产品、追平 Supermemory 全量 UI（工作量为现状 6 倍，与私有化定位冲突）。

> **2026-08-15 修订**：四环「完成」的验收标尺定义于 `docs/web-core-loop-standard.md`（黑盒旅程验收单，与代码形状解耦；v0.7.0 起 web 侧发布门，补全成果随 v0.7.0 与 B3-B6 同发）。原文「移动端可用」延后：标尺仅覆盖桌面 ≥1280px，移动/窄屏无验收项、不阻断发布——此为对本文原范围的显式收窄，移动端可用性恢复时再行修订。
