# 提及是图节点：Mention 区别于 Entity，MENTIONS 是非事实引用类别

B3 NER 层（issue #21）引入「提及（Mention）」——一条记忆所谈论的命名事物，与「实体（Entity = 命名空间）」是两个不同的节点类型。决策三点：(1) 每条提及按实体隔离并解析为共享图节点，(entity_id, 规范形式, 类型) 为去重键，表层别名累积；(2) `(:Memory)-[:MENTIONS]->(:Mention)` 是引用/索引边类别，不是第四种事实关系——不参与 is_latest/replaced_by 时序不变量；(3) 选图节点而非 metadata 标签，因为 B4 多跳推理需要「事实→提及→事实」的物理遍历基底。

**越过 AGENTS.md 关系门槛的辩护**：AGENTS.md 限定事实之间只有三种关系（更新/扩展/推导），新增关系类型需极高论证门槛。MENTIONS 不新增事实关系——它是记忆→概念的引用类别，与记忆→记忆的时序演化正交；且是 B4 多跳的最小必要补充。

**已考虑并否决**：

- metadata 字符串标签：无法跨记忆解析去重（同一事物 N 次提及 = N 份标签），无法支撑多跳遍历——否决。
- 全局共享实体图（跨实体提及链接）：违反实体隔离（ADR-0002 同一个上下文池），永久 out——spec #21 Out of Scope。

**后果**：

- UPDATES 取代时旧记忆保留 MENTIONS 边（历史节点，#26）；遗忘时剪除边并剪除孤立提及节点（#27）——引用类别与时序不变量解耦。
- 提及恰好归属一个实体；不存在跨实体共享提及节点。
- B3 不新增公共 API；实体中心检索与多跳推理延后 B4，以提及节点为物理基底。
