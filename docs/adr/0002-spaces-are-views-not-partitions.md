# Spaces 是视图，不是分区

v0.4.0 后按 Supermemory 的 ContainerTag 模式实现了 Spaces（`:Space` 节点 + Memory 的 `container_tag` 属性）。审视发现它与 AGENTS.md「同一个上下文池」与「全自动」两条原则存在张力。2026-08-09 决定：**Space 是实体记忆的命名子集视图，由用户显式创建（产品层意图，AGENTS.md 原则 4 的明确例外），不改变上下文池边界。**

写死约束：搜索默认全池、空间仅为可选过滤；画像跨空间聚合；`container_tag` 可空（移除当前 `"default"` 伪空间）；系统不自动创建/推断空间。已否决选项：分区模型（空间成为默认作用域，需修改原则 3，制造信息孤岛）；整体回撤（损失已被采用的产品 UX）。
